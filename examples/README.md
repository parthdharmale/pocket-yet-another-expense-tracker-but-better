# Fictional examples

Open `/demo` for an interactive fictional leisure ledger. It requires no account or AI key. The code is in `lib/pocket/demo-data.ts`.

`synthetic-statements.json` contains invented text representations of the HDFC/HSBC layouts and their expected purchase totals. These are parser examples, not real PDFs or account records. `tests/statements.test.ts` builds a synthetic PDF in memory to verify extraction. Never replace these with a real statement in a public contribution.
