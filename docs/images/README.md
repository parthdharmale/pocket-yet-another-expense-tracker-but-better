# Screenshot provenance

All images here were created for this repository using invented examples in an isolated local preview. No production database, real statement PDFs, recordings, account credentials or tokens were used.

- `calendar.png`, `cards.png`, `wishlist.png`, `leisure-insights.png`, `mobile-calendar.png`: the actual Pocket interface using its fictional demo ledger. Mobile is a responsive viewport capture, not a physical-device photograph.
- `spend-analysis.png`, `spending-trend.png`, `amount-labels.png`: the actual statement dashboard rendered with an invented nine-month HDFC/HSBC fixture and synthetic card identifiers. No original statements were uploaded. Screenshot-only fixture routes were kept outside the repository and are not included in the application.
- `shortcut-setup.png`: the actual guide with an example email/domain. The token panel is replaced by an explanatory placeholder in the isolated capture so no credential is generated or displayed.
- `iphone-shortcut.png`: an original HTML/CSS illustration of the supported shortcut flow, not an actual iOS screenshot. Native UI varies by OS version.

Financial figures and projected reductions are examples, not claims about a real person's spending or guaranteed savings. Do not replace these images with private-account screenshots in a public contribution.
